# Gameglory · shared-data — синтетический датасет рынка игр

> Данные синтетические: названия игр, студий и издателей, цифры и тексты отзывов сгенерированы
> и не описывают реальные продукты. Это не выгрузка Steam / SteamSpy, датасет не связан с Valve.
> Совпадения с реальными названиями случайны.

Общий набор данных для тестовых заданий проекта Gameglory (Bear Head Studio, тематика
«Игровая инженерия и интерактивные системы», НИУ ВШЭ). Используется в пакетах:

| Пакет | Как используется |
|---|---|
| `02-ml-nlp-engineer` | основной вход: поиск похожих игр, анализ отзывов |
| `03-backend-developer` | данные для импорта + контракт `mock-api/openapi.yaml` (из `mock-api/` в этом пакете только контракт) |
| `04-frontend-developer` | mock-API (`mock-api/server.mjs` + `db.json`) по тому же контракту |

## Состав

| Файл | Что внутри |
|---|---|
| `games.csv`, `games.json` | 2000 игр (одни и те же данные в двух форматах) |
| `tags.csv` | словарь из 68 тегов: slug, имя, категория, число игр |
| `reviews.csv` | 8883 отзыва для 60 игр (40–200 на игру) |
| `schema.md` | описание полей, форматов и инвариантов |
| `metadata.json` | seed, дата среза, счётчики, дисклеймер |
| `mock-api/` | только в пакетах бэкенда и фронтенда: у бэкенда — контракт `openapi.yaml`, у фронтенда — ещё mock-сервер и `db.json` с описанием в `mock-api/README.md` |

## Основные характеристики

- Релизы 2010-01 … 2026-09 (срез данных — 2026-09-30), число релизов растёт по годам: от ≈20–35 в 2010–2013 до ≈190–210 в 2023–2025.
- Цены кластеризуются на типичных ценовых точках: 9.99 (≈20%), 14.99, 4.99, 19.99, бесплатные (≈12%), 24.99, 29.99 … 59.99.
- Число отзывов — длинный хвост: медиана ≈45, 90-й перцентиль ≈790, максимум ≈84 тыс.; 129 игр без отзывов (`reviews_positive_ratio` пустой).
- 3–8 тегов на игру; теги коррелируют между собой (например, у 71% игр с `roguelike` есть `procedural-generation` при базовой частоте ≈10%; у 94% игр с `farming` есть `relaxing`).
- `short_description` уникальны и собраны из шаблонов, согласованных с тегами и скрытой нишей игры, — поэтому текстовый поиск похожих осмыслен.
- Отзывы на английском, в них заложены 6 тем (баги/производительность, цена, сложность, сюжет, мультиплеер, объём контента) с позитивной и негативной окраской; у каждой игры есть 1–2 «проблемные» темы.

## Ограничения (учитывайте их в выводах)

- Тексты описаний и отзывов шаблонные: словарь ограничен, повторяющиеся фразы встречаются часто. Модели будут
  выглядеть лучше, чем на реальных данных.
- Связь «популярность ↔ качество ↔ цена» задана упрощённо; не делайте по этим данным выводов о реальном рынке.
- `estimated_owners_range` выведен из числа отзывов с шумом (по аналогии с диапазонами SteamSpy) и не является независимой величиной.
